Miten tätä peliä pelataan

Pelialueella on käden kuvia. Alkutilanteessa ainakin osa käsistä on peukalo alaspäin. Tavoitteena on kääntää kaikki peukalot ylöspäin.

Klikkaamalla kädettä kääntyy klikattu käsi ja lähimmät viereiset kädet. Klikkauksen voi perua klikkaamalla samaa kättä uudestaan ennen kuin klikkaa mitään muuta.

Mistä tahansa pelitilanteesta voi palata alkutilanteeseen klikkaamalla Reset-painiketta. Takaisin pelitilanteeseen pääsee klikkamalla Reset-painiketta uudestaan ennen kuin klikkaa mitään muuta.

Numeroiduilla painikkeilla voi valita pelin koon. Suuremmat numerot eivät tarkoita vaikeampia tasoja. Esimerkiksi 9 on helpohko. Saman pelikoon voi valita useita kertoja, jolloin eri kerroilla voi saada eri alkutilanteen. Uuden alkutilanteen voi perua klikkaamalla Reset-painiketta ennen kuin klikkaa mitään muuta.

How to play this game

In the game area there are hand images. In the initial position at least some of the hands are thumbs down. The goal is to turn all thumbs up.

Clicking on a hand will turn the clicked hand and the nearest neighboring hands. You can undo the click by clicking the same hand again before clicking anything else.

You can return to the initial position from any game position by clicking the Reset button. You can get back to the game position by clicking the Reset button again before clicking anything else.

You can use the numbered buttons to select the game size. Higher numbers do not mean more difficult levels. For example, 9 is fairly easy. The same game size can be selected several times, which allows you to get a different initial position each time. You can cancel a new initial position by clicking the Reset button before clicking anything else.
