Tiedostomuodoista

Sudoku-tiedostoille ei ole mitään standardia. Tämä sivu osaa lukea ja kirjoittaa tavallisimpia sudokujen tiedostomuotoja sekä kaikkia itse kirjoittamiaan tiedostoja. Kaikkia näitä tiedostoja voi lukea tavallisina tekstitiedostoina, mutta osa on vaikeasti tulkittavissa.

.svg

Yleisesti käytety kuvatioedostomuoto. Esimerkiksi tavalliset web-selaimet osavat lukea ja näyttää SVG-kuvia. Ohjelmat eivät yleensä osaa lukea sudokutehtäviä SVG-tiedostoista. Tämä sivu osaa lukea itse kirjoittamiaan SVG-tiedostoja.

.txt

Tavallinen teksititiedost, jossa sudoku on ihmisen ymmärrettävässä muodossa kun tiedostoa luetaan ohjelmalla, joka näyttää kaikki merkit (tai ainakin tyhjän ja numerot) samanlevyisenä. Tiedostomuotoa ei ole tarkoitettu ohjelmalla luettavaksi, mutta tämä sivu osaa lukea itse kirjoittamiaan tekstitiedostoja.

.ss

Usein käytetty sudokutiedostomuoto. Tiedostomuoto on uunnitelty ohjelmalla luettavaksi ja on myös kohtullisen helppo ihmisen ymmärtää. Tavallisella tekstieditorilla on myös helppo kirjoittaa .ss-tiedostoja, ASCII- tai UTF-8-muodossa.

.sdk

Tiedostomuoto sukokutehtäville. Sallii myös lisätietoja tehtävästä, mutta tämä sivu ei lisätietoja kirjaoita eikä lue. Tiedostomuoto on suunniteltu koneella luettavaksi, mutt an myös ihmiselle kohtuullisen helppo tulkita.

.sdm

Tiivis muoto tiedostolle, jossa voi olla suurikin määrä sudokutehtäviä. Tämä sivu osaa lukea vain ensimmäisen tehtävän ja kirjoittaa vain yhden tehtävän sisältäviä tiesdostoja.

.csv

Tiedostomuoto taulukkolaskentaohjelmia varten. Yhdeksän ensimmäisen rivin yhdeksän ensimmäistä ruutua on varattu sudokulle.

On File Formats

There is no standard for sudoku file formats. This page can read and write the most common formats of sudoku files and all files it has written. All these files can be read as ordinary text files but some of them are hard to interpret.

.svg

A commonly used graphics file format. For example, typical web browsers can read and show SVG images. Usual programs can't read sudoku problems from SVG files. This page can read SVG files that it has written.

.txt

An ordinary text file that is easily understood when viewed with a program that shows all characters (or at least spaces and digits) with the same width. The file format is not meant for programs but this page can read text files that it has written.

.ss

A commonly used Sudoku file format. The file format is designed to be readable by software and is also reasonably easy for humans to understand. With an ordinary text editor it is easy to create .ss files as ASCII or UTF-8 text files.

.sdk

A file format for sudoku problems. A file may also contain additional information about the sudoku problem but this page does not read or write any additional information. The file format is designed to be readable by software and is also reasonably easy for humans to understand.

.sdm

A way to store many sudoku problems in a single compact file. This page can only read the first problem and can only write files that contain one problem.

.csv

File format for spread sheet programs. The first nine cells of the first nine rows are reserved for the sudoku problem.
